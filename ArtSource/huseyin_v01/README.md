# Hüseyin teslim modeli

13 Ekim 2026 kullanıcı `rustic+craftsman+3d+model.zip` teslimi. Orijinal arşiv değiştirilmeden original.zip olarak tutuldu; SHA256 ve içerik listesi source.json içinde.

FBX Unity'ye yerel importer ile alındı; 29.576 üçgen, 0 skinned renderer, 0 animasyon klibi. Prefab boyu 1,70 m; ölçülen boyut 0,96 × 1,70 × 0,44 m. Taban merkezine oturtuldu, URP renk/normal/metallic-smoothness dokuları 1024 px. Kaynak dokular original.zip içinde tam çözünürlükte.

Tekrarlanabilir import: Farmer.Editor.HuseyinArtSetup.Apply (izole QA projesinde). Sahne dosyasını yeniden üretmez. `ExplorationArt/huseyin` prefabı pazar yanında kullanılır; CapsuleCollider çalışma anında eklenir.
